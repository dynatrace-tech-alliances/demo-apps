# Demo Apps

Setup guides for demo applications used to showcase Dynatrace monitoring.

> These guides are not officially supported by Dynatrace.

## Guides

- [AstroShop on EKS](astroshop/ASTROSHOP-EKS.md) — OpenTelemetry Astronomy Shop demo deployed to Amazon EKS with ALB ingress and Dynatrace OTLP export
- [EasyTrade on Docker](easytrade/EASYTRADE-DOCKER.md) — EasyTrade stock trading demo deployed via Docker Compose on a VM with Dynatrace OneAgent
